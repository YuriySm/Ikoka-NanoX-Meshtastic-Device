Ikoka NanoX (eXtended) Meshtastic PCB is a fork of the [Ikoka Nano Meshtastic Device](https://github.com/ndoo/ikoka-nano-meshtastic-device) created by [Andrew Yong](https://ndoo.sg/projects:amateur_radio:meshtastic:diy_devices:ikoka_nano). This is a modified version of the original design released under CERN-OHL-P.
